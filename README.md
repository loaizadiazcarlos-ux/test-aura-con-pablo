# Test Aura con Pablo

Sitio web de ventas para un restaurante de comidas rápidas, bootstrapped con **Aura Design System** + Next.js.

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS 4 con escala Aura (13px)
- Registro `@aura` (shadcn)
- Cursor rules / skills + DESIGN.md

## Comandos

```bash
pnpm install
pnpm dev
pnpm lint
pnpm build
```

## Aura

```bash
# Componentes del registry
pnpm dlx shadcn@latest add @aura/button

# Identidad visual para imágenes (wiki)
# wiki/obsidian-aura-con-pablo/01-Identity/Image-Identity.md

# Generar imágenes de marca (requiere GOOGLE_API_KEY en .env)
pnpm ai:image -- --help
```
